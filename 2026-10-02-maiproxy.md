description: |
  The WLCG MyProxy service is a centralized certificate repository used to securely manage long-term X509 voms proxy credentials. With the transition from VOMS to IAM, user's job might need an equivalent solution for JWT tokens. The MAIproxy service was built to provide running jobs with fresh JWT credentials when needed. The tool also enable job status reporting capabilities and it has been adopted to run a job campaign over a set of heterogeneous resource providers.
